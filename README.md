## 功能特性

- 🚢 **加载动画**：星空 / 圆月 / 山峦 / 木帆船 / 海浪，进度条与真实资源加载进度**同步**（DOMContentLoaded → 图片解码 → window.load），船随进度从左航行到右，走满 100% 才进入页面
- 💬 **多段提示语**：加载中 8 条航海风提示轮播，减少等待焦虑
- 📊 **数字滚动**：进入视口后统计数字从 0 数起（IntersectionObserver + rAF）
- 🖼️ **灯箱放大**：作品图 / 证书图点击全屏查看，键盘方向键翻页
- 🔍 **作品筛选**：按类型筛选作品卡片
- 🎵 **背景音乐**：可选 BGM（AAC 48kbps 单声道，约 135 秒）
- 📱 **响应式**：桌面端与手机端内容、画面完全一致；移动端证书墙两列、触控热区加大、弹层近全屏
- ♿ **无障碍降级**：`prefers-reduced-motion` 下关闭动画；老内核 `vh` 高度兜底

## 技术实现

- **单文件自包含**：所有 CSS 内联在 `<style>`、JS 内联在 `<script>`，**不拆出任何 `.css` / `.js` / 图片文件**
- **零外部依赖**：不引用任何 CDN、第三方库，纯原生 HTML / CSS / JavaScript
- **媒体内嵌 base64**：32 张图片、1 段 BGM 全部 base64 内嵌进 HTML
- **加载性能**：
  - 图片统一重压（WebP q56 / 长边 1100px，证书扫描件像素级无损保留）
  - 背景音乐压缩为 AAC 48kbps 单声道
  - `decoding="async"`、懒加载、`IntersectionObserver` 按需解码
  - gzip 压缩率约 74%（服务端开启 gzip 时）

## 部署（GitHub Pages）

1. 将单文件 HTML 重命名为 `index.html` 放入仓库根目录（本仓库为 `web-LDS`）
2. 打开仓库 **Settings → Pages**
3. **Source** 选择 `Deploy from a branch`，分支选 `main`（或 `master`），目录选 `/ (root)`
4. 保存后稍等片刻，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

> 仓库根目录推荐同时放置本 `README.md` 与可选的 `LICENSE`。

## 已知问题

- **国内加载慢**：GitHub Pages 在国内直连速度约 100–200 KB/s，首次加载约 20–40 秒；如需更快可换用国内托管 / CDN（当前保持单文件方案，未拆分外链）
